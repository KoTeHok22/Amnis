# CLAUDE.md

Guidance for AI agents working in this repository.

## Проект

**Amnis** — веб-сервис толкования снов (юнгианская психология + ИИ-диалог). Прод: https://amnis.jdh-team.ru/

- **Frontend:** `UI/` — React 18 + Vite 6 + TypeScript + Tailwind CSS v4 + Radix UI (shadcn) + `motion` (framer-motion) + axios. Весь контент на русском.
- **Backend:** `BACK/` — отдельный сервис (auth, профиль, чаты, стриминг, оплата NicePay).
- **Прочее:** `freeLLM/`, `init_db.py`, `docker-compose.yml`, `Caddyfile`.

## Текущая задача

Полное исправление фронтенда по `AUDIT.md`. Прогресс и статусы — в таблице вверху `AUDIT.md` (поддерживать в актуальном состоянии после каждого пункта).

## Архитектура стилей (ВАЖНО)

- Источник стилей — **`UI/src/styles/globals.css`** (импортируется в `main.tsx`). Содержит `@import "tailwindcss"`, `@theme`-токены, `@font-face`, кастомные классы шрифтов, `bg-animation`, reduced-motion.
- Tailwind v4 собирается на лету через плагин `@tailwindcss/vite` (в `vite.config.ts`). Любой класс из компонентов генерируется автоматически.
- **Прекомпилированный `UI/src/index.css` УДАЛЁН.** Не возвращать его и не редактировать руками — менять только `globals.css`.
- Версии `tailwindcss` и `@tailwindcss/vite` зафиксированы на **4.1.17** (должны совпадать).

## Шрифты и бренд

Кастомные шрифты в `UI/src/fonts/`. Декоративные (`Pulstar`/font-tech, `Novem`/font-symbolic, `WildRune`/font-accent) — **только для крупных кириллических акцентов**, НИКОГДА для абзацев, подписей, цифр и латиницы.

- Слово **«Amnis» всегда обёрнуто в `className="brand"`** (читаемый Bainsley/sans). Латиница в Pulstar превращается в руны — не допускать.
- Цифры/числа — `.number-symbol` (теперь display-шрифт) или обычный шрифт, не Novem.
- `h2` по умолчанию = WildRune italic; для консистентности добавлять `font-mystical` (Bainsley).

## Дизайн-система (тёмная «ночная» тема — сохранять)

- Фон `#0D0B24`; акценты: золото `#F4E0A7`, лаванда `#A998FF`; текст `#E8E6F5` / вторичный `#B8B5D1`.
- Один акцент-направление, glassmorphism, плавные `motion` whileInView, 3D-наклон карточек тарифов. Не ломать атмосферу.

## Правила работы

- **Рабочий цикл по каждой задаче из `AUDIT.md` (обязательно):**
  1. **Отметить «Начал»** — поставить статус 🔧 (Начал) в таблице прогресса `AUDIT.md` ДО начала правок.
  2. **Сделать работу** — внести изменения.
  3. **Проверка** — после завершения прогнать проверку (`npm run build`, при возможности визуальная проверка; убедиться, что ничего не сломано).
  4. **Отметить «Закончено»** — только когда всё проверено и проблем нет, поставить ✅ (Закончено) в `AUDIT.md`.
  5. **Взять следующую задачу.** Не начинать новую задачу, пока текущая не отмечена «Закончено».
- Работать в существующем стеке, без миграций фреймворков/библиотек. Перед импортом новой библиотеки — проверить `UI/package.json`.
- Не ломать функциональность. После значимых правок — `npm run build` (и при возможности визуальная проверка через Playwright/Chrome DevTools MCP).
- Не использовать нативные `alert()`/`confirm()` — в проекте есть `sonner` (тосты) и `ui/alert-dialog`. Ошибки валидации — инлайн под полем.
- Никаких `console.*` в проде — при необходимости логировать через guard `import.meta.env.PROD`.
- Изменения держать сфокусированными и обратимыми; статус отражать в `AUDIT.md`.
